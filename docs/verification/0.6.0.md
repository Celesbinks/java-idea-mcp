## English

The implementation follows the design-first hybrid architecture: retain nineteen native tools, add two operation-management tools, and reuse the available official providers. The complete baseline is 77 tools; the isolated sandbox and independent Codex client discover 73. Four optional Qodana inspection tools cannot load because this local Ultimate module requires an installation-specific startup extension; their real provider integration remains dynamic and their calls are unverified.

Regression covers the original temporary-JVM tests, real platform file/search/refactoring calls, read-only VCS/database/debugger queries, launch-field redaction, operation cancellation, safe client configuration updates, a standalone Java stdio process, and independent Codex discovery/calling. SQL workloads, official debugger evaluation/writes, terminal execution, official builds and interactive confirmation UI have not all been exercised end-to-end. Other client products were validated with configuration fixtures rather than launched. No new native replacement is claimed faster without equivalent-result evidence. Install the generated ZIP and reload the client separately; source, installed-plugin and current-chat versions are distinct.

All **70 JUnit tests**, **94 protocol assertions**, `buildPlugin verifyPluginStructure`, and local-script packaging checks passed. External Codex integration was enabled in the final full run. The delivered ZIP is the Gradle artifact with a SHA-256 sidecar. The current chat still discovers the earlier nineteen native tools and fifty-six official tools until the new package is installed and the client is reloaded.
