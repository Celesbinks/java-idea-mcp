## 同条件与完整性

三个任务均调用 list_directory_tree，projectPath 指向当前项目，maxDepth=100、timeout=10000。
每轮每条件每方预热 3 次、正式 80 次，各先 40 次；独立两轮，第二轮反转条件及提供方顺序。
双方串行查询；本轮未并发运行构建或 JFR 诊断，也未插入其他 MCP 查询。
不重试替换失败样本，不删最大值；每次拒绝 isError、errors 非空、listingTimedOut。

比较完整 MCP 返回对象，包括 content 文本、structuredContent 和 isError；
只规范化对象键顺序，保留数组顺序和目录树每个字符。两个客户端的冻结结果也逐一完全相同。
取样结束后，将树解析为完整相对路径/目录类型集合，与磁盘递归清单逐项比较，三个范围全部一致。

## 决策与复现

保留现有 0.6.7。本轮证实大规模受控宽目录在生产端点有明确收益，小目录回退成本很小；
小规模自然宽根没有稳定收益且 HTTP P95 有轻微回退，不能宣传所有宽目录都加速。
若后续继续调优，优先验证小规模宽根的资格选择；本轮按用户范围仅复验，不改阈值、
不增加缓存或生成新包。冷根与首次启动不由本次预热后的数据保证。

忽略目录 build/benchmarks/067-installed 保留：
trees.mjs、production.json、expected.json、summary.json、current-codex.json、
current-codex-expected.json、current-codex-summary.json、audit.mjs、manifests.json、
connection.json、installed-artifact.json、源码前后摘要及 fixture-wide。
两个 Node 客户端会话已结束；没有遗留新服务进程。
