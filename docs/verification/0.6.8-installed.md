## 结论与边界

保留 0.6.8。目录密集形状已经正确避免旧 NIO 路径，大树收益确认，普通宽根没有
引入新的数量门槛。自然宽根 P95 仍是已知限制；不继续套用普通文件数阈值或结果缓存。
若后续继续定位，应先分开观察渲染中的身份校验与输出成本，取得同条件证据后再决定改动。

目录密集树相对 0.6.7 的 **57.9%～58.3%** 提升仍属于
[独立沙盒旧版对照](0.6.8-directory-qualification.md)。本轮没有回滚生产 IDEA，
也没有同时可用的旧版生产端点，因此不编造对应的生产旧版提速百分比。
0.6.7 的旧生产耗时不能与本轮不同时间段直接相减归因为版本变化。

本轮仅新增验证记录与中英文 README 链接；Git 实现、参数、设置保持不变，未执行
Git 性能实验。0.6.8 的 112 项测试、94 项协议断言和独立沙盒证据沿用上述发布报告，
不冒充本轮重新构建或重跑。已安装包与发布包一致，不需生成新版本。

原始数据位于忽略目录 `build/benchmarks/068-installed`：trees.mjs、production.json、
summary.json、expected.json；current-codex.json、current-codex-summary.json、
current-codex-expected.json；audit.mjs、manifests.json、final-audit.json；以及 connection.json、
installed-artifact.json、source-before.json、source-after.json。初次 schema 探测记录保留为
probe-schema-mismatch.json，不混入正式样本。结果与路由、平衡顺序均由 final-audit.mjs 检查。
